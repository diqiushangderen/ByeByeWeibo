# ByeByeWeibo
用来网页版批量删除微博的代码，写作于2026.1
新增了转换为仅自己可见微博代码，写作于2026.4

### 一、使用指引

1. 使用 Chrome、Edge 或其他 Chromium 内核浏览器打开 [网页版微博](https://weibo.com)。
2. 进入个人主页，利用搜索框或筛选功能，确定需要删除/仅自己可见的目标范围（如搜索关键词、筛选特定时间等）。
3. 删微博：
   - 按下 `F12` 键，打开开发者工具。
   - 切换到 **Console（控制台）** 选项卡。
   - 复制并粘贴本仓库中的脚本代码`DeleteCode.js`。
   - 按下 `Enter` 回车键，启动脚本。
4. 仅自己可见微博：
   - 按下 `F12` 键，打开开发者工具。
   - 切换到 **Console（控制台）** 选项卡。
   - 复制并粘贴本仓库中的脚本代码`PrivateCode.js`。
   - 按下 `Enter` 回车键，启动脚本。

---

### 二、故障处理与技巧

* **手动停止**：脚本运行过程中，如需立即停止，直接 **刷新网页 (F5)** 即可销毁所有进程。
* **加载卡顿**：若一直没有有效删除，请 **手动用鼠标滚轮上下滑动一下页面**。
* **频率限制**：若微博提示“操作过于频繁”，说明触碰了平台风控，请刷新页面并建议休息1小时后再继续。
